# Quality & Style

- Short, purposeful paragraphs; avoid marketing fluff.
- Prefer Roboto for text and Roboto Mono for code (via theme defaults).
- Use Material icons where a visual cue genuinely helps.
- Keep code examples self-explanatory without inline commentary.
- Treat docs like code: versioned, linted, and reviewed.

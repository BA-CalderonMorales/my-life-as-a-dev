  <p class="portfolio-section__label">01 <span>/</span> Ownership</p>
  <div class="portfolio-section__content">
    <p class="portfolio-overline">Scope over labels</p>
    <h2 id="ownership-title">Ownership at the seams.</h2>
    <p class="portfolio-lede">My title is senior software engineer. The work is platform-shaped: I own the connective systems around security remediation, AI-assisted delivery, documentation, and release governance.</p>

    <article class="portfolio-outcome" aria-labelledby="outcome-title">
      <div class="portfolio-outcome__story">
        <h3 id="outcome-title">From a backlog to a repeatable operating model.</h3>
        <p>At Fiserv, I am the technical delivery owner for AI-enabled vulnerability remediation across 20+ engineering teams. During one two-week effort, I helped reduce a third-party-identified security backlog from about 4,000 findings to about 200 remaining.</p>
        <p>The meaningful part was not a single script. It was building a shared path from intake and triage through assignment, remediation, pull-request review, and deployment, while keeping engineers responsible for the decisions.</p>
        <p class="portfolio-outcome__sequence">Intake <span>/</span> Triage <span>/</span> Assignment <span>/</span> Remediation <span>/</span> Review <span>/</span> Deployment</p>

<section class="portfolio-section" id="practice" aria-labelledby="practice-title">
  <p class="portfolio-section__label">02 <span>/</span> Practice</p>
  <div class="portfolio-section__content">
    <p class="portfolio-overline">What the work looks like</p>
    <h2 id="practice-title">The systems behind the outcome.</h2>
    <p class="portfolio-lede">I tend to work on the connective tissue teams feel immediately when it is missing.</p>

    <div class="portfolio-practices">
      <article class="portfolio-practice">
        <span class="portfolio-practice__number">01</span>
        <h3>Secure agentic delivery</h3>
        <p>Design repeatable coding-agent workflows with approved inputs, versioned prompts and tools, human review, observable handoffs, and rollback plans.</p>
      </article>
      <article class="portfolio-practice">
        <span class="portfolio-practice__number">02</span>
        <h3>Vulnerability remediation</h3>
        <p>Correlate signals across security platforms, reduce duplicate noise, establish priorities, and make ownership unambiguous.</p>
      </article>
      <article class="portfolio-practice">
        <span class="portfolio-practice__number">03</span>
        <h3>Delivery infrastructure</h3>
        <p>Standardize GitHub Actions, CI/CD, secrets, service accounts, and release governance so automation has a dependable path to production.</p>
      </article>
      <article class="portfolio-practice">
        <span class="portfolio-practice__number">04</span>
        <h3>Documentation as infrastructure</h3>
        <p>Treat documentation as a maintained system: versioned, tested, deployed, and useful during onboarding, triage, and change.</p>
      </article>
    </div>
  </div>
</section>

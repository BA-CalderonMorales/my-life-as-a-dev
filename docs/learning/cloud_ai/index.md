## Prerequisites

Before starting any guide, you should have:

!!! note "Requirements"

    1. **Cloud Account**: Google Cloud (for Vertex AI guides)
    2. **Python**: Basic knowledge of Python programming
    3. **CLI**: Comfort with command line operations

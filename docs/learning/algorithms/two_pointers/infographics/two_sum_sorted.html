How it Works:

The Two Pointers technique uses two pointers starting at opposite ends of a sorted array. Based on the sum of the elements at both pointers:

  • If sum equals target: Found the answer!
  • If sum is less than target: Move left pointer right to increase sum
  • If sum is greater than target: Move right pointer left to decrease sum

Time Complexity: O(n) - single pass through the array
Space Complexity: O(1) - only two pointers needed

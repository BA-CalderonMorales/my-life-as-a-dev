How it Works:

The Sliding Window technique maintains a window of k elements and slides it across the array. Instead of recalculating the sum for each window from scratch (O(n*k)), we:

  • Calculate the sum of the first window
  • Slide the window by removing the leftmost element and adding the new rightmost element
  • Update the maximum sum if the current window sum is larger

Time Complexity: O(n) - single pass through the array
Space Complexity: O(1) - only a few variables needed

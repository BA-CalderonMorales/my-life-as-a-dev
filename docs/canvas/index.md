# The Canvas Exhibition

We believe geometry, motion, and interaction are infinite. Below are twenty uniquely divergent variations stemming from three foundational structures—**Zen Geometry**, **Crystal Cave**, and **Particle Flow**. Each transforms standard WebGL into breathtaking, jaw-dropping, and intuitive visual experiments that beg to be explored.

Brandon Calderon Morales

Omaha, Nebraska. English and Spanish. Engineer, Marine veteran.

I wanted to be a dev before I knew that was a job. Video game nerd first, a few wrong directions, then right back to poking at machines.

The road here: court reporter for the Marines (where the typing speed comes from), React and Java at Leidos, classified SAIC work I still can't talk about, now Fiserv.

The day job

Technical delivery lead on two efforts. When a vulnerability storm hits, I coordinate 20+ engineering teams and show them how coding agents plus our security stack (Fortify, Wiz, SonarQube) squash findings faster than legacy code ever allowed. The other: observability — one clear portfolio picture, so leadership stops squinting.

Alongside: CI/CD for hundreds of repos, Coder dev environments, and a grassroots push to make innovation a habit instead of a slide deck.
